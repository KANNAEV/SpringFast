- Spring многомодульный фреймворк
- Ядро спринг - springcorre (содержит контекст для управления бинами)
- Бин - это объект java помеченный на включение в контекст приложения
- Способ добавления в контекст бинов:

1) Анотация @Bean
    - создать класс конфигурации и пометить его как @Configuration
    - Внутри класса добавить все нужные иобъекты и пометить каждый как @Bean
    - в Main функции при создании экземпляра контекста указать файл конфига

```java
var context = new AnnotationConfigApplicationContext(AppConfig.class); 
```

2) Стереотипные анотации
    - Отметить аннотацией @Component те классы, экземпляры которых вы хотите
      поместить в контекст Spring
    - в класе конфигурации добавить путь где искать компоненты приложения для
      контекста : `@ComponentScan(basePackages = "имя_пакета")`

- Стереотипные аннотации хороши всегда (меньше кода), а @Bean — лишь когда нет других вариантов (например, когда вы
  создаете бин для класса, являющегося частью библиотеки, и не можете изменить этот класс, чтобы добавить в него
  стереотипную аннотацию)
