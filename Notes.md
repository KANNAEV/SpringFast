## Введение
- Spring многомодульный фреймворк
- Ядро Spring - SpringCore (содержит контекст для управления бинами)
- Бин - это объект java помеченный на включение в контекст приложения

## Способы добавления в контекст бинов:

### 1) Аннотация @Bean
    - создать класс конфигурации и пометить его как @Configuration
   - Внутри класса добавить все нужные объекты и пометить каждый как @Bean
    - в Main функции при создании экземпляра контекста указать файл конфига

    ```java
    var context = new AnnotationConfigApplicationContext(AppConfig.class); 
    ```
   - Если нужно несколько бинов 1 класса - присвой ему имя `@Bean(name = "kewa")`
   - Если нужно пометить вариант бина по-умолчанию - пометь его как `@Primary`
   - Аннотация @Bean удобна, когда нужен бин для класса, который не можете изменить, чтобы добавить в него
     стереотипную аннотацию

### 2) Стереотипные аннотации 
- Сокращает код
- Отметить аннотацией @Component те классы, экземпляры которых вы хотите поместить в контекст Spring
- в классе конфигурации добавить путь, где искать компоненты приложения для контекста : `@ComponentScan(basePackages = "имя_пакета")`
- Стереотипные аннотации хороши всегда (меньше кода), а @Bean — лишь когда нет других вариантов 
- Контролировать создание экземпляра можно через @PostConstructor с методом init (jakarta.annotation-api)
- Сделать что-то перед закрытием и очисткой контекста @PreDestroy (но нежелательно)
- `@Component` — базовый стереотип. Универсальная аннотация для любого Spring-компонента
- `@Service` — для сервисного слоя. Используется для классов, содержащих бизнес-логику
- `@Repository` — для DAO/репозиториев. Для классов, работающих с базой данных. (авто трансляция исключений БД в Spring исключения).
- `@Controller` — для веб-контроллеров. Используется в MVC для обработки HTTP-запросов (возвращает представления).
- `@RestController` — для REST API Комбинация @Controller + @ResponseBody. Используется для RESTful веб-сервисов.

- Задать дополнительные инструкции после создания бина: `@PostConstruct`
- Для этого нужно определить метод в классе компонента и снабдить этот метод аннотацией @PostConstruct
- Необходима зависимость `implementation("jakarta.annotation:jakarta.annotation-api:3.0.0")`

### 3) Программное добавление бинов (Spring 5)
- Добавление в контекст новых бинов используя существующие в контексте

```java
if (condition) {
    registerBean(b1); //Если условие истинно, добавить в контекст Spring некий бин
} else {
    registerBean(b2); //Иначе: добавить в контекст Spring другой бин
}
```

- `Supplier` — это функциональный интерфейс, который входит в пакет Java.util.function. 
- Назначение реализации Supplier - возвращать заданное значение, не принимая параметров.
- Чтобы программно добавить бин в контекст Spring, достаточно вызвать метод registerBean()
```java
<T> void registerBean(
        String beanName, // Имя бина, можно указать null если оно не нужно
        Class<T> beanClass, // Класс из которого создаем бин
        Supplier<T> supplier, // чтобы возвращать значение экземпляра, добавляемого в контекст
        BeanDefinitionCustomizer... customizers); // интерфейс, для настройки различных свойств бина
```
- Шаги:
- 1) Создание экземпляра, который будет добавлен в контекст Spring
- 2) Определение Supplier, который будет возвращать этот экземпляр
- 3) Вызов метода registerBean(), добавляющего экземпляр в контекст Spring
